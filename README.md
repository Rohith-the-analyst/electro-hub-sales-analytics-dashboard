# Electro Hub Sales Analytics Dashboard

## Project Overview
This project is an interactive Power BI dashboard developed for Electro Hub to analyze sales performance, profit trends, customer behavior, product performance, and promotional impact.

The dashboard provides business insights through dynamic visualizations, slicers, trend analysis, and comparative reporting.

---

## Features
- Executive sales overview
- Top & Bottom 5 product analysis
- Sales vs Profit comparison
- Interactive visual filtering
- Trend analysis using date hierarchy
- Dynamic slicers for filtering
- Geographical sales analysis
- Promotion and discount analysis

---

## Tools & Technologies Used
- Power BI
- Power Query
- DAX
- Data Modeling
- Star Schema

---

## Key KPIs
- Total Sales
- Net Sales
- Total Profit
- Units Sold
- Total Orders
- Average Discount

---

## Dashboard Pages

### 1. Executive Overview
Provides high-level business insights including:
- Sales trends
- Profit analysis
- City-wise sales
- Discount category analysis

### 2. Top & Bottom Product Analysis
Analyzes:
- Top 5 products by sales/profit/quantity
- Bottom 5 products by sales/profit/quantity

### 3. Sales & Profit Comparison
Allows comparison between selected time periods for:
- Sales
- Profit
- Quantity sold

### 4. Interactive Filtering Analysis
Demonstrates advanced visual-level filtering using measures and slicers.
